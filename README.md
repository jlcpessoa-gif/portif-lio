# Portfólio · Júlio César

Site do editor de vídeo Júlio César — https://jcesar.vercel.app

Site estático (HTML, CSS e JS num arquivo só) em `site/`. Conteúdo em `site/content.json`.
Publicado pela Vercel a cada push. Instruções completas para agentes em `CLAUDE.md`.

Ferramentas do dono, só pelo endereço:
- `?ajustes` — painel de animação + timeline (DialKit)
- `?feedback` — marcar elementos e gerar instruções para o agente (Agentation); `?feedback=mcp` envia para o MCP local
